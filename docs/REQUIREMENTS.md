# 山泉弹珠台 · 需求文档

## 产品目标

为洞庭山泉制作一个打开链接即可玩的品牌小游戏：把一滴拟人山泉从地下 180 米，经岩层、源头灌装和江南山城配送，送到生活场景的杯子里。72 小时被压缩成最长 72 秒的一局。首版部署至 Vercel，兼容桌面键盘与手机触摸，无登录门槛。

## 一局流程

1. 进入青绿山水风格的立体弹珠台，看到地下水源、源头站、城市与三种杯子；点击「开始送水」或按空格发射。
2. 「地下 180 米」：水滴进入岩层弹珠区，碰撞矿石机关积累 180 米的出泉进度。
3. 「源头灌装」：达到水源进度后，击中源头灌装站完成封装，配送轨道开放。
4. 「山城配送」：选择茶山、加班桌或球场路线，操作挡板将水滴送入发光配送入口；终点显示对应生活场景的杯子。
5. 成功：播放进杯、水波与根据本局碰撞音符生成的短旋律；展示分数、耗时、目的地和个人最佳纪录，可一键重玩。
6. 失败：72 秒耗尽或用尽 3 次水滴救援后，显示明确原因，可立即重玩。

## 操作与反馈

- 桌面：← / A 左挡板，→ / D 右挡板；空格开始或重新发射；↓ / S 切换配送岔路；P 或 Escape 暂停。
- 手机：左右两个不少于 44px 的触摸挡板按钮，独立发射和路线按钮，支持双指同时操作，避免页面滚动抢走游戏输入。
- 计时只累计有效游玩时间；页面切入后台自动暂停，继续需要显式操作。
- 撞击有弹性运动、光晕、水花和短音；静音开关持久化，首个用户操作后才解锁声音。
- 分数、剩余时间、旅程阶段、救援次数、所选路线始终可辨认；不只依靠颜色表达状态。
- 桌面与手机均采用保持原始 540:820 比例的球台，等比放大而不拉伸；桌面侧置分数和按钮，手机按钮位于下方。开始后进入专注模式，保证挡板和发射按钮同屏；提供返回介绍入口。
- 结算后点击杯子立即切换本局送达场景，不等待下一局，保持分数、耗时、送达数不变；杯子纪录按本局基线重新结算。
- 规则说明、暂停、重新开始、声音和场景选择均可键盘访问；支持减少动态效果偏好。

## 品牌与画面

- 品牌：洞庭山泉；核心数字为用户提供的「地下 180 米」「最快 3 天」，作为本次概念的关卡设定，不额外创造认证、疗效或供应承诺。
- 采用用户授权的 `D:\Code\WaytoAGI-Short-formdrama\images\materials` 商品与背景素材，筛选后复制必要文件到本仓库并记录来源。
- 主球台直接采用其中《山林航拍全景》的真实山林画面，而不是仅将实景放在说明弹窗中。
- 主视觉为有纵深的微缩江南山城弹珠机：青绿山峦、白墙黛瓦、泉水轨道、暖黄机关、玻璃水滴。
- 不依赖远程图片与字体才能游玩；核心美术使用本地 SVG / Canvas，3D 观感通过等距层次、阴影和材质实现。
