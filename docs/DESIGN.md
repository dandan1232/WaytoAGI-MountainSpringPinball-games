# 视觉与交互方案

## 方向：一座可以弹起来的江南山城

页面是游戏本体。桌面以原始比例的竖向大球台为主，分数和按钮位于球台左侧，目的地位于右侧；介绍压缩为上方一行，开始游戏后收起。手机采用近全宽竖向球台，主按钮位于下方并与球台同屏，目的地和纪录再往下排列。

```text
洞庭山泉                   山泉游乐场              声音 / 玩法
────────────────────────────────────────────────────────────
把一滴山泉，送进生活里。
分数 / 剩余秒  ┌────── 原比例球台 ──────┐  这次，送到哪里？
暂停 / 重玩    │ 真实山林照片 / 村落    │  茶山茶杯
水滴救援       │ 源头灌装 / 岩层机关    │  加班水杯
左挡板         │ 泉水轨道 / 配送入口    │  球场运动杯
发射 / 右挡板  │ 水滴 / 左右机械挡板    │
               └──────────────────────┘  本机送水纪录
```

## 设计令牌

- 深松绿 `#123E35`：标题、主按钮、重要数据。
- 泉水青 `#43BBA7`：水滴、轨道、活跃状态。
- 雾白 `#F3F8F2`：大面积背景。
- 苔绿 `#A8C99B`：山体与植物层次。
- 暖金 `#E9B951`：弹珠机关、碰撞、计时提醒。
- 岩石灰 `#728A7A`：地层与辅助图形。

中文展示字优先本机宋体，正文使用系统黑体，数字与英文标签使用等宽字体。所有字体均有本地回退。字形与青绿水景呼应，不把游戏做成默认的暗色霓虹街机。

## 标志性构图

真实山林照片直接成为主球台的上半部背景；下方叠加村落、泉水轨道与地层。整个球台、圆形机关、房屋、挡板、照片、文字与商品图采用统一缩放，禁止通过横向拉伸来扩大游戏界面。桌面使用侧边分数和控件腾出纵向空间。暖黄立体挡板和实际桶装水灌装站使品牌与玩法共享同一画面。

按用户反馈删除「THE JOURNEY / 72 小时 → 72 秒 / 选一条小路，把山泉送进杯子」介绍模块及「每一滴，都有来处。」文案。结算后的杯子选择立即改变本局展示，不再出现下一杯预选状态。

## 检查与取舍

本地 UI/UX 检索第一次返回通用像素街机方案，与本项目自然山水题材不匹配；改用水与自然的轻盈游戏查询后，采用其触摸、对比度和柔和层次建议。保留为本项目制定的青绿 palette、微缩山城和中文字体，不照搬通用产品页、像素字体或整屏霓虹。

必要的球体运动保持清晰；装饰动效服从减少动态设置。重要控件最小 44px、明确 focus，发射与开始使用稳定名称，失败说明具体原因。
