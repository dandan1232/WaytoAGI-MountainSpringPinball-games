# 视觉与交互方案

## 方向：一座可以弹起来的江南山城

页面是游戏本体。桌面采用横向大球台与右侧目的地的两栏结构，介绍压缩为上方一行；开始游戏自动收起介绍。手机采用近全宽竖向球台，主按钮与球台同屏，目的地和纪录位于下方。

```text
洞庭山泉                   山泉游乐场              声音 / 玩法
────────────────────────────────────────────────────────────
把一滴山泉，送进生活里。
┌──────── 分数 / 剩余秒 / 暂停 ────────┐  这次，送到哪里？
│       用户素材中的真实山林照片      │  茶山茶杯
│       白墙村落 / 源头灌装站         │  加班水杯
│       玻璃轨道 / 岩层机关           │  球场运动杯
│       水滴 / 配送入口 / 左右挡板    │
└──────── 同屏操作按钮 ──────────────┘  本机送水纪录
```

## 设计令牌

- 深松绿 `#123E35`：标题、主按钮、重要数据。
- 泉水青 `#43BBA7`：水滴、轨道、活跃状态。
- 雾白 `#F3F8F2`：大面积背景。
- 苔绿 `#A8C99B`：山体与植物层次。
- 暖金 `#E9B951`：弹珠机关、碰撞、计时提醒。
- 岩石灰 `#728A7A`：地层与辅助图形。

中文展示字优先本机宋体，正文使用系统黑体，数字与英文标签使用等宽字体。所有字体均有本地回退。字形与青绿水景呼应，不把游戏做成默认的暗色霓虹街机。

## 标志性构图

真实山林照片直接成为主球台的上半部背景；下方叠加村落、泉水轨道与地层。桌面的横向俯视投影拉开机关距离，手机保留纵向球道。照片、文字与商品图保持实际比例。暖黄立体挡板和实际桶装水灌装站使品牌与玩法共享同一画面。

按用户反馈删除「THE JOURNEY / 72 小时 → 72 秒 / 选一条小路，把山泉送进杯子」介绍模块及「每一滴，都有来处。」文案。结算后的杯子选择立即改变本局展示，不再出现下一杯预选状态。

## 检查与取舍

本地 UI/UX 检索第一次返回通用像素街机方案，与本项目自然山水题材不匹配；改用水与自然的轻盈游戏查询后，采用其触摸、对比度和柔和层次建议。保留为本项目制定的青绿 palette、微缩山城和中文字体，不照搬通用产品页、像素字体或整屏霓虹。

必要的球体运动保持清晰；装饰动效服从减少动态设置。重要控件最小 44px、明确 focus，发射与开始使用稳定名称，失败说明具体原因。
