# 视觉与交互方案

## 方向：一座可以弹起来的江南山城

页面是游戏本体。桌面中央为纵向玻璃弹珠机，左侧为品牌标题和旅程说明，右侧为送水目的地与本机纪录。手机优先展示标题、状态、球台与触摸控件，其余内容在下方。

```text
洞庭山泉                   山泉游乐场              声音 / 玩法
────────────────────────────────────────────────────────────
把一滴山泉，     ┌──分数───剩余秒──┐      这次，送到哪里？
送进生活里。     │  远山 / 源头站  │      茶山茶杯
                 │  江南白墙村落   │      加班水杯
180m 出泉        │  玻璃弯轨与矿石 │      球场运动杯
源头灌装         │    拟人水滴     │
72h → 72s        │  左挡板 右挡板  │      本机送水纪录
                 └─操作与发射按钮─┘
```

## 设计令牌

- 深松绿 `#123E35`：标题、主按钮、重要数据。
- 泉水青 `#43BBA7`：水滴、轨道、活跃状态。
- 雾白 `#F3F8F2`：大面积背景。
- 苔绿 `#A8C99B`：山体与植物层次。
- 暖金 `#E9B951`：弹珠机关、碰撞、计时提醒。
- 岩石灰 `#728A7A`：地层与辅助图形。

中文展示字优先本机宋体，正文使用系统黑体，数字与英文标签使用等宽字体。所有字体均有本地回退。字形与青绿水景呼应，不把游戏做成默认的暗色霓虹街机。

## 标志性构图

纵向球台是江南山城的立体剖面：地底层叠岩石从下部托起源头村落，溪流变成玻璃轨道，拟人水滴沿轨道穿行。暖黄立体挡板和瓶装水灌装站使品牌与玩法共享同一画面。场景中的立体感由光照面、侧面、投影与前后遮挡实现。

## 检查与取舍

本地 UI/UX 检索第一次返回通用像素街机方案，与本项目自然山水题材不匹配；改用水与自然的轻盈游戏查询后，采用其触摸、对比度和柔和层次建议。保留为本项目制定的青绿 palette、微缩山城和中文字体，不照搬通用产品页、像素字体或整屏霓虹。

必要的球体运动保持清晰；装饰动效服从减少动态设置。重要控件最小 44px、明确 focus，发射与开始使用稳定名称，失败说明具体原因。
