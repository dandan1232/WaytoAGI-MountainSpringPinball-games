# 品牌素材来源

由项目用户授权使用：

- `spring-water.webp`：原始素材《洞庭山_桶装天然泉水产品图_倒置.png》，等比缩小至宽 240 像素并转换 WebP，用于球台源头灌装站。保留产品图本身方向与标识。
- `source-forest.webp`：原始素材《山林航拍全景.png》，保留原始宽 1280 像素并转换 WebP，直接用于主球台的真实山林背景，也用于玩法说明。按显示区域裁切，保持照片实际比例。

村落、轨道、机关、水滴和三种终点场景由本项目 Canvas / SVG 代码原创绘制；山林使用上述真实素材，无远程图片依赖。

项目代码采用 MIT 许可证。品牌名称、标识、商品图片和山林照片的权利归各自权利人所有；代码许可证不改变这些素材的权利归属。`docs/screenshots/` 是本项目的实际运行截图，包含上述品牌素材。
